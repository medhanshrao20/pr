# Reported Brentwood results

Open comparison.md for the three-model table and highlighted best errors. The per-experiment metrics are stored in L/results/reported_2025, L.1/results/reported_2025 and spatial_L.1/results/reported_2025.

brentwood_comparison.csv is the wide table; brentwood_metrics_long.csv contains all 36 original records; best_results.csv lists 36 metric winners; win_counts.csv summarizes them. spatial_improvements.csv uses 100*(baseline-spatial)/baseline: positive values mean spatial improves over that baseline.

These are user-reported metrics, not newly generated forecasts. Full run artifacts were not supplied. Provenance and verification limits are in provenance.json. MAPE_nonzero is not counted again in wins because it equals MAPE for every supplied row. No model or existing experiment code was changed.

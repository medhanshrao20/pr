# Spatial L.1 — Brentwood-only spatial forecast

Run `python run.py --run-id experiment_name --year 2025`. There is no Spatial L experiment. The other 13 stations provide potential context; the final output and neural training loss are **Brentwood only**.

Brentwood preprocessing and hybrid VMD selection follow the unchanged copied L.1 functions. If the same-ID L.1 baseline has matching config/data/year, reuse its selected Brentwood K/alpha; otherwise execute the same selection again. Neighbors use the same original seasonal cleaning and L.1 parameter-selection rule. All station windows align to the original Brentwood split/origins; missing neighbor measurements are filled by the inherited full-season cleaner rather than discarding different Brentwood samples.

Neighbor features are individually projected to the Brentwood feature dimension. With graph row A_47 and projected node features p_j, context=sum_j A_47,j p_j and enriched Brentwood input=LayerNorm(x_47+GELU(W context+b)). The original KANInformer temporal backbone forecasts the residual from this enriched input. This is a basic GCN-style weighted layer, not GAT. Default graph: geographic three-nearest-neighbor symmetrized support, Gaussian distance weights, self loops and row normalization. Inspect the saved adjacency to see which stations actually contribute; all 13 need not have direct nonzero edges. Optional statistical/combined graphs are training-row based.

Ridge receives **only Brentwood's original features**, so its forecast, residual definition, residual MinMaxScaler, optimizer, cosine schedule and early stopping remain the original L.1 scheme. New graph context is provided only to the neural residual path. The copied L.1 training function is reused by supplying spatial-only model/Ridge-input adapters in this new experiment; the protected baseline runs receive no such adapters and source files are not modified.

Save: own/neighbor K-alpha selections, graph CSV, per-node feature labels/scalers, cleaned input audits, Brentwood predictions, training histories and checkpoint. Root collector compares with L and L.1 only after verifying identical targets/timestamps. Spatial checkpoints require the saved node schema/scalers/graph and the Brentwood Ridge coefficients to reconstruct inference; no streaming deployment command is implemented.

Full-season decomposition and cleaning leakage are retained. Default CPU matches the protected baselines. This new spatial adapter accepts CUDA, but baseline CUDA remains unsupported without changing their inherited validation path; no such baseline change is made. See the root description for math, strict MAPE versus separate nonzero MAPE, commands and fair-comparison limitations.
